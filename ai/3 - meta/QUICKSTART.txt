🚀 QUICK START GUIDE
====================

Welcome to the 3D Globe Location Tracker!

OPTION 1: DOUBLE-CLICK TO OPEN
------------------------------
Simply double-click `index.html` to open in your default browser.

OPTION 2: LOCAL SERVER (RECOMMENDED)
------------------------------------
1. Open a terminal in this folder
2. Run one of these commands:

   Python 3:
   python -m http.server 8000

   Node.js:
   npx http-server

   PHP:
   php -S localhost:8000

3. Open your browser to: http://localhost:8000

FIRST STEPS
-----------
1. Type a city name (e.g., "Tokyo", "Paris", "New York")
2. Press Enter or click "Add City"
3. Watch the pin appear on the globe!
4. Add more cities to see flight trails connect them
5. Click and drag to rotate the globe
6. Use mouse wheel to zoom
7. Click table rows to focus on specific cities

CONTROLS
--------
⌨️  KEYBOARD & MOUSE:
   • Click + Drag = Rotate globe
   • Mouse Wheel = Zoom in/out
   • Click table row = Focus on city

📱 TOUCH DEVICES:
   • One finger drag = Rotate
   • Two finger pinch = Zoom
   • Two finger drag = Pan

🎮 CONTROL BUTTONS:
   • + = Zoom in
   • − = Zoom out
   • ⟲ = Reset view
   • ↻ = Toggle auto-rotation

TIPS & TRICKS
-------------
✓ Your cities are automatically saved (no account needed!)
✓ Try adding cities from different continents to see curved flight trails
✓ Click the 🗑️ icon to delete a city
✓ Use "Clear All" to start fresh
✓ The globe auto-rotates when you're not interacting with it
✓ Works offline after first load (cities are saved locally)

TROUBLESHOOTING
---------------
❌ Globe not showing?
   → Check if your browser supports WebGL: https://get.webgl.org/
   → Try Chrome, Firefox, Edge, or Safari (latest versions)

❌ Cities not saving?
   → Check if you're in private/incognito mode
   → Some browsers block localStorage in private mode

❌ "City not found" error?
   → Try being more specific (e.g., "Paris, France" instead of just "Paris")
   → Check your internet connection

HAVE FUN! 🌍✈️
